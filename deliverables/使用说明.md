# 小爱音量助手 · SoundPilot（测试版）使用说明

## 一、这是什么

SoundPilot 是「小爱音箱语音通知工具」的 Windows 桌面版（测试包），用于**在游戏或特定程序运行时，自动把小爱音箱音量调低**，退出后按设置恢复日常音量。

- Rust + Tauri 2 + Vue 3 桌面重写，默认浅色界面
- 通过 xiaoi Webhook 控制音箱音量，不是音频驱动，不影响蓝牙延迟
- 首次启动**默认启用监控**：打开即开始识别规则
- 未配置音箱 / 服务器地址时，程序不会发送任何音量请求，可放心体验界面

> **搭配使用**：本工具需配合 [onepve/xiaoi](https://github.com/onepve/xiaoi) 部署的 Webhook 服务（上游为 [xvhuan/xiaoi](https://github.com/xvhuan/xiaoi)）。上方仓库已修复内存泄漏，并新增**获取音箱实时音量**能力，供本工具写入后读回核验。

## 二、快速开始

1. 解压到任意目录（建议英文路径，如 `D:\SoundPilot\`）
2. 把 `soundpilot.json` 与 `soundpilot.exe` 放在**同一目录**（本包已附转换好的配置）
3. 首次使用也可在「设置 → 配置导入 / 导出」导入旧的 `config.ini`：会先展示差异预览，确认后写入
4. 在「设置 → 音箱设备」核对 DID 与启用状态；在「服务连接」核对地址与 Token
5. 在「游戏与平台」页确认规则（或从「平台模板」快速创建、调整目标音量）
6. 回到首页，确认状态为「监控运行中」

> `soundpilot.json` 也可以手工编辑，与 EXE 同目录。Token 仅保存在本机；导出配置时自动去除 Token。

## 三、界面说明

| 页面 | 功能 |
|---|---|
| 首页 | 监控状态、暂停/恢复、定时暂停（到点自动恢复）、手动音量（先暂停自动监控再写入，避免互相抢音量）、运行日志 |
| 游戏与平台 | 规则增删改查：搜索、分类筛选、顺序调整（即优先级）、复制、删除二次确认、多进程关联、运行程序选择、常用平台模板 |
| 设置 | 服务连接（地址/Token）、多音箱启用管理、日常音量、无规则回落、同组匹配模式、检测间隔、退出缓冲、启动即暂停、开机自启、配置导入/导出 |

### 运行日志

- 仅保存在内存中，**最多保留 200 条**（超出自动丢弃最旧的），不写磁盘、不磨损硬盘
- 卡片右上角提供「**清空日志**」按钮，带二次确认；清空不影响监控运行与配置

### 系统托盘与开机自启

- 关闭窗口不会退出程序，而是**最小化到托盘**继续监控；真正退出请用托盘菜单或程序内退出
- 托盘菜单：打开主窗口、暂停监控、恢复监控、退出
- 开启「开机自动启动」后，登录 Windows 会**自动启动并直接最小化到托盘**静默运行，不弹窗打扰

## 四、规则匹配逻辑

- **游戏优先于平台**；平台之间按列表顺序（或最高音量，见设置）
- 进程匹配：填了完整路径则按路径精准匹配；只填进程名则不区分大小写
- 一条规则可关联多个进程，任一运行即命中
- 无规则命中时按「回落方式」处理：回到日常音量 / 恢复原音量 / 保持不动

## 五、安全提示

- **请勿转发本压缩包与 `soundpilot.json`**：其中包含你的服务器地址、音箱 DID 与 Token
- 不要同时运行旧版 Go 监控程序和本工具，避免音量互相覆盖
- EXE 尚未代码签名，Windows 可能弹 SmartScreen 提示：仅在确认文件来源与哈希后运行
- 暂停只停止本程序自动调音量，不会停止音箱播放或其他自动化

## 六、本测试版已知边界

- 需 Windows 10/11 x64 + Microsoft Edge WebView2 Runtime（一般随系统更新自带）
- 真机进程检测与音箱链路请实机验证
- 定时暂停仅停止自动调音，到点自动恢复监控
